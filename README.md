# Уникализатор видео

Автономный скилл для подготовки вариантов готового ролика. Он слегка меняет кадрирование, поворот,
цвет, скорость и звук, очищает исходные метаданные и экспортирует MP4. Поддерживает MOV и MP4
со звуком или без. Работает локально через Python и FFmpeg.

## Установка

1. Установите Python 3.9+ и FFmpeg с кодировщиками libx264 и AAC. Команды `python3` и `ffmpeg`
   должны быть доступны в Терминале.
2. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его.

   ```sh
   git clone https://github.com/wooddecorq-ai/unikalizator-video.git
   cd unikalizator-video
   ```

3. Для агента положите папку `unikalizator-video` с `SKILL.md` и `scripts/` в каталог его навыков.
   Пример запроса: «Сделай три версии `input.MOV` и сохрани MP4 в отдельной папке».

## Запуск из Терминала

```sh
python3 scripts/unikalizaciya.py "input.MOV" "out/variant-01.mp4" --profil myagko
python3 scripts/unikalizaciya.py "input.MOV" "out/variant-02.mp4" --profil sredne --crop 0.06 --angle -0.4
```

`myagko` по умолчанию даёт кроп 4% и скорость 101%. `sredne` задаёт кроп 8% и скорость 98%.
Кроп 4% означает примерно по 2% с каждой стороны. Для готового видео с подписями у краёв
проверьте несколько кадров перед публикацией. Рядом с MP4 будет JSON с настройками и проверками.

Исходник и существующие результаты защищены от перезаписи. Для HDR и видео с неквадратными
пикселями сначала нужен экспорт в SDR с квадратными пикселями. Скилл проверяет целостность
результата и отличие файла от исходника. Решения соцсетей об оригинальности контента
зависят от их собственных правил.

Все параметры доступны через `python3 scripts/unikalizaciya.py --help`.
