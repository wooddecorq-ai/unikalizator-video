# Уникализатор видео

Обрабатывай локальный исходник через `scripts/unikalizaciya.py`. Скрипту нужны Python 3.9+
и FFmpeg с libx264 и AAC в PATH. Подходят SDR-ролики с квадратными пикселями, со звуком или без.

1. Уточни исходник только если из запроса и файлов его нельзя однозначно определить. Используй
   указанную папку вывода и отдельное имя MP4 для каждой версии.
2. Для одного результата запусти скрипт с `--profil myagko`. Этот профиль даёт кроп 4%,
   поворот +0,25° и скорость 101%. `--profil sredne` задаёт верхний уровень изменений
   с кропом 8%, поворотом −0,6° и скоростью 98%.
3. Для нескольких версий обработай каждую из исходного файла. Разводи настройки кадрирования,
   поворота или темпа в пределах `--crop` 0–0.08, `--angle` ±0.6°, `--speed` 0.98–1.02,
   `--pitch` 0.99–1.01. Кроп указан суммарно по каждому измерению, а не на один край.
   На кадрах с подписями или деталями у края начни с меньшего кропа.
4. Проверь код завершения и поле `checks` в JSON рядом с MP4. Если доступны кадры просмотра,
   проверь, что важные детали и подписи целиком в кадре. В ответе укажи, где лежат готовые MP4.

```sh
python3 scripts/unikalizaciya.py input.MOV out/variant-01.mp4 --profil myagko
```

Скрипт выводит H.264/AAC в MP4, сохраняет ориентацию и приводит размеры кадра к чётным. В отчёте
есть параметры, seed, локальные пути и результаты проверки. Результаты обработки описывай
как версии исходного ролика. Решение соцсети об оригинальности по отчёту определить нельзя.
